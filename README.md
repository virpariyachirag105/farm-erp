# Farm ERP

A full-stack Farm Management ERP built with **FastAPI, PostgreSQL, React, and TypeScript**.

## Features

- JWT Authentication
- Role-Based Access Control (RBAC)
- Farm Management
- Season Management
- Season Partner Management
- Dealer Management
- Product Management
- Dispatch Management
- Free Dispatch Management
- Dispatch Settlement
- Dealer Payments
- Expense Management
- Season Box Cost Management
- Partner Settlement

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Alembic
- JWT Authentication

### Frontend
- React
- TypeScript
- Vite
- Material UI
